# Dataset

Download `cardio_train.csv` from the [Cardiovascular Disease dataset](https://www.kaggle.com/datasets/sulianova/cardiovascular-disease-dataset).

For the Colab notebook, place the original semicolon-separated CSV at:

`MyDrive/COMP721 Project/data/cardio_train.csv`

The notebook mounts Drive at `/content/drive`, cleans the data and writes intermediate CSVs and model artefacts to the project folder. Run its cells in order. This repository does not redistribute the dataset or generated model files.
